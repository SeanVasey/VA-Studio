# vasey-license-pdf-v2 profile provenance

Production buyer license profile, increment 5 (part 1) of [the production contract profile](../../../docs/production-contract-profile.md):
the successor of `vasey-license-pdf-v1` decided on 2026-11-08 ([decision register](../../../docs/architecture/decision-register.md)).
It keeps v1's three brand families and adds Latin Extended. v1 and its directory are unchanged.

It is **built, not selected for issuance**, and has no renderer yet. `App\Domain\Contracts\Production\VaseyLicenseV2Profile`
pins this directory by the SHA-256 of `profile-assets.json`; the manifest pins every file below, the tc-lib package graph
and the implementation closure (the profile definition and the checkout printable set,
`App\Domain\Commerce\ContractIdentity\ContractPrintableSet`, which both production checkouts use).

Everything except the three Latin Extended sources is generated by `php scripts/build-contract-profile-vasey-license-v2.php`,
and `php scripts/build-contract-profile-vasey-license-v2.php --check` rebuilds it in a temporary directory and compares it
byte for byte. `--archives=DIR` also proves every source face and license is the member of its npm tarball, read only
after the tarball matches its pinned SHA-256 and npm `sha512` integrity.

- `fonts/source/`: the SIL Open Font License 1.1 faces and texts, all from the Fontsource 5.3.0 tarballs that
  `public/brand/fonts/source-manifest.json` already pins (`@fontsource/bebas-neue`, `@fontsource-variable/reddit-sans`,
  `@fontsource-variable/jetbrains-mono`). None declares a Reserved Font Name.
  - the three `latin` subsets and the license texts are byte copies of the brand files in `public/brand/fonts/`;
  - the three `latin-ext` subsets are vendored here, because the brand directory has only Latin. Their SHA-256 values are
    pinned in the build script: Bebas Neue `16c95ce45a2922f52551d38d565d14c92cf257b8f219c89613407d81fdd21a39`,
    Reddit Sans `1f4049cb63a3088a505d98719f509f3fadcf5dde4424c9d675b1826ec28d262b`, JetBrains Mono
    `79bfdab9ba467e26eea4122e6f2567e188dd8a09a8c730d501fc487c4ab99c6e`.
- `fonts/ttf/`: static TrueType built by `scripts/vasey-license-v2-fonts.py` with fontTools 4.68.0 and brotli 1.2.1. Each face
  is its `latin` subset merged with its `latin-ext` subset (fontTools `merge`, Latin first), so every outline is the upstream
  glyph v1 already uses. Reddit Sans is instanced at `wght` 400 and 700 and JetBrains Mono at 400 before the merge; the 700
  instance is renamed `RedditSans-Bold`. `head.created` and `head.modified` are restored from the Latin source, so the output
  does not depend on the build time.
- `fonts/generated/`: tc-lib-pdf-font 4.4.1 `util/convert.php` output (TrueTypeUnicode, flags 32, platform 3, encoding 1).
- `images/vasey-audio-logo.png`: a byte copy of `public/brand/vasey-audio-logo.png`, never redrawn or recreated.

**No signature is stored here or anywhere in Git.** The profile names the same configured signature pin as v1.

The four faces have 359 positive-width codepoints in common, all Latin or Common (v1: 214), and the D-30 rule accepts 357 of
them (v1: 212). Greek, Cyrillic and Vietnamese are not in every face (Bebas Neue has no Vietnamese) and stay refused.
