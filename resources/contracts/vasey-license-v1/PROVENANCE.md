# vasey-license-pdf-v1 profile provenance

Production buyer license profile, increment 4 of [the production contract profile](../../../docs/production-contract-profile.md).
It is **built, not selected for issuance**. `App\Domain\Contracts\Production\VaseyLicenseProfile` pins this directory by
the SHA-256 of `profile-assets.json`; the manifest pins every file below, the tc-lib package graph and the renderer
implementation files.

Everything here is generated by `php scripts/build-contract-profile-vasey-license-v1.php`, and
`php scripts/build-contract-profile-vasey-license-v1.php --check` rebuilds it in a temporary directory and compares it
byte for byte.

- `fonts/source/`: byte copies of the brand faces and their SIL Open Font License 1.1 texts from `public/brand/fonts/`,
  checked against `public/brand/fonts/source-manifest.json` (Fontsource 5.3.0 packages, Latin subsets): Bebas Neue 400,
  Reddit Sans (variable `wght`) and JetBrains Mono (variable `wght`). None declares a Reserved Font Name.
- `fonts/ttf/`: static TrueType decoded from those woff2 files by `scripts/vasey-license-fonts.py` with fontTools 4.68.0
  and brotli 1.2.1. Bebas Neue is decoded as is. Reddit Sans is instanced at `wght` 400 and 700, and JetBrains Mono at
  400; the 700 instance is renamed `RedditSans-Bold` so the PDF never embeds two programs under one PostScript name.
  `head.modified` is kept from the source, so the output does not depend on the build time.
- `fonts/generated/`: tc-lib-pdf-font 4.4.1 `util/convert.php` output (TrueTypeUnicode, flags 32, platform 3,
  encoding 1, the faces' only Windows cmap).
- `images/vasey-audio-logo.png`: a byte copy of `public/brand/vasey-audio-logo.png` (SHA-256
  `7b0ffd26d5ddffab9695fdd3e0a4bb306d50642dc6a51e25233fd1626ff07571`). It is drawn unmodified at its own aspect ratio on
  the charcoal band; the logo is never redrawn or recreated.

**No signature is stored here or anywhere in Git.** Sean's signature PNG is read at render time from the private local
disk (`VASEY_LICENSE_SIGNATURE_PATH`, relative to `storage/app/private`) and must match `VASEY_LICENSE_SIGNATURE_SHA256`;
a missing or changed file refuses issuance. Tests use a generated stand-in image only.

The faces are Latin subsets: they cover 214 codepoints in common, far fewer than the DejaVu faces of `test-buyer-pdf-v2`.
See the coverage notes in the production contract profile document before activation.
