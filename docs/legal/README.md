## Legal pages: publication mechanism

No route, page type or template renders a privacy notice or terms page today (`app/Domain/SiteBuilder/SiteContentSchema.php`; `routes/web.php`). The activation packet lists "Legal pages (privacy, terms)" as an input that lands in `docs/legal/` (`docs/ops/production-activation-packet.md`, section 2), and `CLAUDE.md` records `docs/legal/` PRIVACY and TERMS as an open standard-adoption gap. Publishing them to buyers needs one of: a reviewed site-content page type (a code change outside this lane), or hosting the approved text elsewhere and linking it from the contact page copy. Acceptance of terms at checkout is today the frozen `assent.text` of the order policy (`docs/order-preparation.md`), which is S-8.
