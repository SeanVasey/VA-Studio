# Tax HTTP rehearsal boundary

Both `paid-tax-grants.http_mounted` and `production-tax-checkout.http_mounted` ship as literal `false`. Only exact boolean `true` in `local` or `testing` permits route/provider registration. Mounting supplies neither commerce policy nor merchant facts. The conditional producer provider binds only `UnboundTaxCheckoutTransport`; its enabled flag, provider, funds mode, account and return origin retain their refusing defaults. Actual merchant activation, credentials, money, host deployment and cutover require Sean's separate authorization and inputs on the host.

For an explicitly authorized local/testing rehearsal, configuration and route caches must be cleared and rebuilt under the intended literal flags and environment. Use the normal Laravel `config:clear` / `route:clear`, then the application's chosen `config:cache` / `route:cache` procedure. A previously built route cache cannot gain newly enabled routes from a later setting alone. Conversely, the per-request root guard refuses false/nonboolean flags or a non-rehearsal environment even when a previously mounted route collection remains loaded. The tests exercise loaded route collections; this packet does not claim a host cache rebuild or deployment.

The consumer's six identifier-only routes use web sessions, actual CSRF, session blocking and bounded throttles without Inertia. There is no Tax page/history index in this slice. JSON body intake is bounded at64KiB/depth16; native redemption accepts at most4KiB of exact token+CSRF fields. The producer retains its16KiB/depth8 parser and one raw-resource intake. Framework cached-body normalization and the producer's deliberate two JSON decoding passes remain distinct from that raw intake.

The first mounted consumer root seam captures one original redemption budget before body, identity and controller work. Its exact-request WeakMap value holds no Request reference; reservation, failed-capture tombstone and one controller claim prevent renewal. Native core server backing storage is read without getter hooks. Headers, body fields and mutable request attributes cannot supply or replace this budget. Original elapsed admission, snapshot and transfer caps remain domain-owned.

Original projection/transfer handles belong to a plain response owner. An unstarted response must be explicitly closed or disposed; encoding/construction/callback failure and destruction close those original handles without erasing a committed attempt. Successful JSON proves its original read immediately before bytes. A late JSON refusal may retain an already prepared200 header but emits only a generic error body. A refused attachment emits no appended error JSON; a durable attempt remains spent, and a fresh authorization is needed for retry. Neither behavior establishes successful delivery or renews entitlement.

All errors for both prefixes remain private JSON regardless of `Accept`, including failures ahead of privacy middleware. Reports contain only a fixed message and exception class. Private fields are excluded from framework flashing; response headers use no-store/no-referrer/noindex/nosniff and Cookie Vary. Rate/Allow metadata is bounded and allowlisted. In the real mounted producer web pipeline, CSRF exceptions are rendered by Laravel before the delegated privacy middleware receives its response; the original anticipated mapping concern was disproved by actual equality/mismatch/rotation tests.

Local sessions, cache locks, SMTP and provider inputs are synthetic fixtures. Current native, distributed cache, FPM/send-timeout, performance/capacity, global SQL/DDL/isolation/reopen/restore, existing-request final provider-I/O and real commercial/legal/account/provider/host activation remain unverified by this HTTP packet. Preserve `docs/ops/paid-delivery-runtime.md` and all prior release conditions. No frozen contract profile, schema or original producer/consumer domain was changed.
