## Existing typed seams

`App\Domain\Customers\ProductionCustomerAccess` is an injected instance service.
`principal(User)` mints `ProductionCustomerPrincipal` from current persisted
identity; clients cannot construct it from HTTP arrays. `lock(principal, actor,
CurrentRows)` returns held current raw evidence; `proveCurrent(..., expectedRaw)`
rechecks that original evidence. `durableBinding(principal)` exposes only safe
origin/account/observation identities and hashes. It proves email/account control,
not a legal buyer name or address. The buyer must explicitly declare those facts.

Use `ProductionCustomerSessions::principal(Request)` for the actual T23 session
marker and `request->user('customer')` as the trusted actor. The sealed free HTTP
capsule uses `ProductionFreeGrantHttpIdentity::binding(Request)` and provides
`principal()`, `actor()` and `proveCurrent()`. Keep that same request-bound capsule
through terminal HTTP proof. Marker/resolver/guard/cached actor/session/key changes
after a callback cannot be ignored. `forRequest()` remains the existing pair API;
it does not retain a future consumer's terminal HTTP proof on its own.

Original identity history uses `verifyHistoricalBinding(binding, CurrentRows)`
and `proveHistoricalBindingCurrent(..., expectedRaw)`. Current account authority
must still be checked independently. No raw owner key, password, credential stamp,
challenge token or private history parser should be projected into public DTOs or
copied into a grant producer's private implementation.

Approved committed validation uses `IdentityCommittedFrame::begin(CurrentRows,
originalDeadlineNs)` after an ordinary Laravel commit/events. It owns one read-only
raw transaction at framework depth zero, with a one-use physical sentinel,
SQLite query_only / native READ ONLY and READ COMMITTED visibility. Call access
`proveCommitted(principal, actor, frame, originalRaw)`, original-binding committed
proof as required, then `finish()` before returning a prebuilt DTO. Do not start
business writes or renew the original deadline in this mode. Admission must still
reject custom application PDO/PDOStatement callbacks before any SQL.

Historical e8 receipts are a different mode:

```php

    array $binding, CurrentRows $reader, array $expectedHistoricalRaw,
```
