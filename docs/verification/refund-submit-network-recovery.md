## Confirmed mechanism and scope

The pinned Livewire 4.4.6 native form-submit listener disables the submit button before sending the message. The button's separate `wire:loading.attr="disabled"` directive then captures that already-disabled attribute. On network failure, message finish callbacks first undo the form's disabled state and later restore the attribute captured by the button directive. Submit therefore becomes disabled again. The original trace matches this ordering: the loading spinner stops, Filament's `isProcessing` visuals remain false, and the only subsequent requests belong to the error notification component.
