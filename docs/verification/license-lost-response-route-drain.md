Pinned Playwright **1.63.0** distinguishes handler removal from callback completion. In `playwright-core/lib/coreBundle.js`, the client `Page.unroute()` calls `_unrouteInternal(..., 'default')`; that path removes registered handlers and updates interception patterns without calling `RouteHandler.stop()`. `unrouteAll({ behavior: 'wait' })` removes handlers and calls `stop('wait')`, which waits for the active non-thrown invocations' completion promises. `_handleInternal()` awaits both the route-handling promise and user callback; `_handleImpl()` resolves each completion promise in its `finally` block. A browser `requestfailed` event alone does not supply this callback-completion barrier. No callback error suppression is added.
