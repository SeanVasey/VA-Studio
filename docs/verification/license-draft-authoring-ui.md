# Reviewed license-draft editor

The ordinary license-version **Edit** action now captures `ReviewedLicenseDraft::review()` when its modal opens and fills from that exact display. Locked review and action/table context are consumed before form validation or visibility checks, then passed privately to `updateReviewed()` for the same operator and record. Neither a stale save nor another click silently captures a fresh baseline. Content, dates, schema validation, authorship, independent approval, successors and publication retain their existing domain rules.

A rejected or unconfirmed save retains the entered source, terms and dates in the modal, with a visible source-field error and explicit copy/reopen guidance. Reopening reads the durable current draft. Failed-open guidance makes no claim that a save occurred or that a form remains open. Required current MFA and operator authorization are checked again; changed action arguments, record, table context or unsupported form fields invalidate the capture. Existing policy-row UUID error mapping and modal focus recovery remain intact.

Economic policy add/delete/reorder controls are native Filament schema actions. Only a verified visible policy repeater in the captured parent form, its exact native context and bounded existing-row arguments can preserve the original review through their synchronous child lifecycle. That private handoff never recaptures a review or persists an exemption. Parent retargeting and malformed child arguments still consume the review.

The edit submit button uses the same supported local attribute override as the independently diagnosed refund-modal recovery: native `wire:submit.prevent` owns disabling and cleanup; the second `wire:loading.attr` owner is omitted. Spinner, target, processing state and focus attributes remain rendered. No vendor or global button change is made.
