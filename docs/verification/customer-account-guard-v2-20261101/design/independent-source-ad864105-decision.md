That classifier executes database/table queries, five SHOW CREATE probes, namespace catalogs, trigger/context queries, full indexes, columns and FKs/constraints. This structurally defeats the purpose of G1's once-per-frame complete proof for that parent floor; prose acknowledging increased cost does not preserve that requirement. It also magnifies every reader/terminal invocation before any restored member headroom measurement.

Reuse only under the existing witness/session/counter token and held account metadata lock, with explicit reasoning: another connection cannot CREATE/DROP its account trigger or ALTER the pinned table until the transaction ends; same-connection persistent DDL implicitly commits and invalidates witness; temporary shadows change existing counters. Do not solve cost by caching full schema indefinitely, dropping version pinning, weakening complete terminal proofs or expanding the cost bound. Measure unchanged IdentityInspectionCostTest bound110 and downstream proof/statement counts on the repaired source. Performance/headroom remains unproven regardless of source repair.
