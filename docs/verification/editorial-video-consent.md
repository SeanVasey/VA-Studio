# Visitor-controlled editorial video

T16's video increment uses the already validated public YouTube/Vimeo descriptor. No provider iframe, thumbnail, SDK, preconnect or stored consent is created before an explicit **Load video** action. Loading pauses the store's audio preview but does not request video autoplay. The public watch link remains available. Removing the iframe stops this page displaying it and returns keyboard focus to Load; it cannot undo information already sent to the provider. Each new page/video or public/private transition needs fresh intent. Private staff previews expose neither playback nor the external watch link.

The component reconstructs only fixed provider URLs from a canonical identifier and matching canonical watch URL; arbitrary iframe URLs are rejected. Frames use restricted sandbox/permissions and an origin-only cross-origin referrer. YouTube uses its privacy-enhanced domain; Vimeo requests DNT. The interface still explains that connecting sends the visitor's IP address and the provider may use cookies. This is a per-video load choice, not marketing enrollment, a blanket legal consent assertion or a promise of zero tracking.

Primary provider references checked October 1, 2026: [YouTube embedding/privacy-enhanced mode and referrer requirement](https://support.google.com/youtube/answer/171780?hl=en-GB), [YouTube player parameters](https://developers.google.com/youtube/player_parameters), and [Vimeo player parameters, DNT and essential-cookie limitation](https://help.vimeo.com/hc/en-us/articles/12426260232977-About-Player-Parameters). Provider availability, domain restrictions, deleted videos and real-device playback still need staging verification with approved actual videos. No third-party SDK or dependency was added.

Local frontend validation covers intent/removal/focus, no storage or pre-load frames, invalid descriptors, and video/private-preview transitions. The native spec intercepts synthetic provider responses while retaining actual keyboard/DOM/iframe requests; it establishes the loading boundary, not real provider playback or server publication authorization. Record exact executed counts and browser results on the integrating PR. Related-track associations and broader T16 remain open.
