## Operator sequence once the authoring environment is ready

1. Use the protected operator account and create private tracks from reviewed metadata. Keep a durable original outside the application and retain the source manifest.
2. Upload artwork/master and applicable stems; request processing and inspect its actual outcome. Resolve scanner, format or integrity failures. Confirm tagged-preview sound/levels, full duration and waveform with the actual file.
3. Associate applicable stems with the processed master after checking the source session. Record real rights references and sample disclosures; complete the declaration review.
4. Enter actual license source/structured terms, obtain the separate review, publish the approved license and create an offer for the exact verified deliverables. Draft saves do not change an already published commercial revision.
5. Inspect protected track review and every readiness blocker. Use the accepted publication boundary on the installed version; confirm its manifest compare/apply acceptance against the current queue and actual installed source. Track scheduling is separate remaining work. Verify public preview/artwork while masters, untagged files and private evidence remain protected.
6. Keep purchases in the supported test environment until production commerce is implemented and the complete real-provider test flow below passes. A public catalog/share page does not establish a live checkout path.
